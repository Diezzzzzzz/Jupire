- **OpenGameArt** : page consultée individuellement pour confirmer le tag de licence CC0 explicite (icône + lien `creativecommons.org/publicdomain/zero/1.0`) et l'auteur (`quaternius` pour les packs Quaternius, uploads directs pour boar/deer/raven/esox).
