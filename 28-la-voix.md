# La voix — cris et sifflets sur touches rapides

> L'idée (Rémi) : déplacement en point & click, et des **touches rapides
> (1-2-3-4…)** pour émettre des sons — un sifflement pour attirer
> animaux/humains, un cri pour faire peur, un cri pour alerter, un cri pour
> signaler sa position ou un danger.

## Pourquoi c'est l'étage manquant du canal

Tous les étages corporels du doc 24 (affect, deixis, mimesis) exigent d'être
**vu** — co-présence visuelle. Or le doc 05 l'avait posé : « le son comble la
vue » — on entend avant de voir, ou sans voir. **La voix est le seul canal qui
fonctionne sans se voir** : dans le brouillard, la nuit, la forêt, derrière le
méandre, dans le noir d'une grotte. Elle manquait ; la voici.

## Le set primal (petit, universel — même garde-fou que les emotes)

4-5 vocalisations maximum, toutes pré-linguistiques, lisibles par tout humain
(et par les animaux) sans convention :

1. **Le sifflement** — appeler, attirer (humains, animaux).
2. **Le cri d'alarme** — la peur qui prévient (universel : tout le monde
   comprend « danger » sans l'avoir appris).
3. **Le cri de menace** — faire fuir (bête, intrus).
4. **L'appel de position** — le « ohé » : je suis là / où êtes-vous ?
5. (Le **chant** reste un support d'énoncé, doc 23 — pas une touche réflexe.)

Garde-fou identique aux emotes (doc 24) : **rien que du primal**. Jamais de
« cri qui veut dire échange » — le sens riche doit s'inventer.

## La combinatoire gratuite — le Silbo de la gorge

La vraie profondeur ne coûte rien : **rythme, répétition, séquence**. Deux
sifflements courts ? Trois longs ? Court-long-court ? Le jeu n'y attache AUCUN
sens — les communautés, si. Précédent réel : le **Silbo Gomero**, langue
sifflée des bergers de La Gomera (Canaries), qui porte à plusieurs kilomètres
à travers des ravins profonds — une géographie qui est exactement celle de
Balazuc. Nos joueurs inventeront leurs codes sifflés (le berger, la vigie du
mât — doc 26, le passeur de gué), et **chaque culture aura les siens** :
entendre un code qu'on ne connaît pas = savoir qu'on est en terre étrangère,
à l'oreille. La géographie culturelle (doc 17) devient audible.

## Le prix du son : il est public

Un cri ne choisit pas ses auditeurs. **Tout ce qui est dans le rayon entend** —
l'ami, le loup, le bandit. L'alerte qui sauve le village révèle ta position ;
le sifflet qui attire le gibier attire peut-être autre chose. La furtivité
(doc 18) gagne son versant sonore : se taire est un choix, crier est un
engagement. Et le monde-acteur joue : le **vent** (docs 08, 18) porte ou
étouffe, la **gorge résonne** (l'écho du doc 05 — on crie dans la gorge et
la falaise répond), la pluie noie tout.

## Ce que perçoit l'auditeur

Direction + distance grossière (fort/faible) + la déformation du terrain
(écho, étouffement). De loin : « un cri d'alarme, vers l'amont, lointain ».
Jamais : qui, pourquoi. Signal partiel pur — il faut **aller voir** (l'étoile
polaire jusque dans l'oreille).

## Contrôles (orientation posée)

- **Déplacement : point & click** — cohérent avec la vue du doc 06.
- **La voix : touches directes (1-4), instantanées** — la voix doit être un
  réflexe, jamais un menu. On crie *plus vite* qu'on ne parle : c'est sa
  nature, l'interface doit la respecter. (Les énoncés composés — croquis,
  symboles — gardent leur interface posée, doc 23 ; la voix est l'exception
  rapide.)

## Verdict mantra

**Passe.** Le son porte loin mais dit peu ; le sens riche reste à inventer
(codes) ; crier coûte (révélation) ; comprendre un code étranger demande
l'apprentissage. Trahisons : un ping silencieux sur la carte, un cri
directionnel qui n'alerte que les alliés, du voice chat réel.

## Questions ouvertes

- Le set exact : 4 ou 5 ? (Un son de deuil/détresse distinct de l'alarme ?)
- **L'intensité** : maintenir la touche = plus fort, porte plus loin — mais
  révèle plus loin ? (Instinct : oui, superbe arbitrage.)
- Les animaux : table de réactions par espèce (le gibier fuit le cri, vient au
  sifflet ? le loup… vient au cri de détresse ?) — à lier au bestiaire.
- Anti-spam : le souffle (crier essouffle, on ne mitraille pas les touches) ?
- Le cri s'entend-il en mode Regard (doc 26) — la vigie qui entend ET voit ?
