# Cycle, persistance & but

> Les trois questions existentielles d'un monde persistant. La plupart des réponses
> découlent déjà des mantra.

## 1. Le cycle de gameplay — fractal (4 boucles emboîtées)

Le même geste à chaque échelle : **réduire une distance.**
- **Instant (secondes)** : percevoir (regarder, scruter, écouter) → s'approcher → agir
  (ramasser, feu, peindre, tenter de se comprendre) → réagir.
- **Session (~1h)** : revenir → *lire ce qui a changé* (monde vieilli, brume, nouvelles)
  → poursuivre un fil (enseigner, rassembler pour un projet, voyager, entretenir le
  village, suivre un grief) → laisser une trace → se déco en ayant changé le monde.
- **Vie (plusieurs sessions)** : naître → apprendre → contribuer & se lier →
  mener/fonder/explorer → vieillir → mourir → bilan & hommage.
- **Générations (plusieurs vies/joueurs)** : cultures naissent, divergent, prospèrent,
  guerroient, déclinent, s'éteignent → légendes & ruines. Le monde = protagoniste persistant.

## 2. Déconnexion & village rasé — la règle juste

Instinct « vivre même déconnecté » = bon, MAIS piège mortel = si le perso peut être
*tué* hors-ligne → offline raiding (Rust/Ark), 1re cause de rage-quit, injustice qui
trahit l'esprit (la perte doit venir d'un *moment vécu*).

**Règle : le monde vit, la trace persiste, le personnage se repose.**
- **Monde + structures persistants**, peuvent changer (construire/dégrader/raser) par
  les joueurs *en ligne*, dans le temps.
- **Les personnes ne risquent leur vie que présentes.** Déco = le perso se retire (dort,
  s'abrite), pas une cible. **Pas de meurtre hors-ligne.**
- **Ré-entrée là où l'on s'est reposé** (abri, village) → raison de s'enraciner (l'abri =
  point de ré-entrée). Vagabond → revient où il a dormi.

**Village rasé pendant l'absence ?** On **survit** (pas tué hors-ligne) mais on revient
**survivant découvrant les ruines** → pas de la triche, du **deuil**. On **revit l'image
fondatrice** (arriver seul dans un monde de ruines). La perte nourrit le thème. Ouvre le
chapitre suivant (reconstruire ? retrouver les survivants ? venger ? emporter le savoir ?).

→ **Perte du LIEU** = possible hors-ligne, tragique. **Perte de la VIE** = uniquement
dans un moment vécu/présent. Juste ET thématique.

## 3. Pourquoi jouer / le but

> Le but de Jupire = le but d'une vie : **compter pour les autres et laisser une trace,
> avant de mourir.** Le système de « score » existe déjà = le **résumé de vie**.

Pas de but extrinsèque (high-score, loot, « gagné »). But intrinsèque = sa force.
Moteurs de rétention (cf. Minecraft, EVE, Journey, Dwarf Fortress) :
- **On a besoin de toi / tu as une place** (appartenance, rôle : gardien du feu, lecteur
  d'étoiles, sachant-bateaux). La plus forte rétention qui existe.
- **Ta trace persiste** : progression = empreinte sur le monde + chez les autres, pas des stats.
- **Le monde a changé sans toi** : curiosité de revenir.
- **La fragilité te rend essentiel** : tout peut se perdre → ta présence compte → **tu
  importes parce que tu es perdable.** 100 % les mantra.

Le but profond : vivre une vie qui a réduit la distance, mourir d'une mort dont on se
souvient, puis recommencer ailleurs et vivre mieux. **La boucle des vies = le méta-jeu.**
