# Motivation : le besoin, pas la récompense

> Tentation récurrente et DANGEREUSE : « où est la récompense ? pourquoi faire tout ça ?
> ajoutons des bonus / avantages ». C'est le piège que l'étoile polaire interdit. Ce doc
> est le garde-fou.

## La peur est légitime

Un jeu anti-jeu-de-pouvoir n'a pas de carotte (loot, niveaux, victoire). « Pourquoi faire
ça ? » est LA question existentielle. Si une action n'a aucune raison d'être, personne ne
la fait. Le problème de motivation est réel — à ne pas balayer.

## Mais « bonus / récompense » = la trahison

Un buff danglé pour pousser à une action (commercer, etc.) :
- transforme l'acte humain en **optimisation de tableur** (le drame meurt) ;
- donne du **pouvoir gratis** (anti-jeu-de-pouvoir brisé) ;
- **masque si le jeu fonctionne vraiment** : avec des bonus, on ne sait jamais si l'acte
  est *intrinsèquement* prenant. La carotte cache un cœur peut-être mort.

## La clé : RAISON ≠ RÉCOMPENSE

- **Récompense** = cadeau artificiel agité pour faire faire un truc autrement vide.
- **Besoin** = raison *intrinsèque au monde* ; ne pas le faire a de vraies conséquences.

> **On ne *récompense* pas une action. On la rend *nécessaire*.**
> Jupire ne pousse pas avec une carotte ; il tire avec un **besoin**.

Ex. commerce : on ne commerce pas pour un bonus → on commerce parce que sans sel, **le
peuple ne passe pas l'hiver**.

## Concret : le besoin est cousu dans la géographie

Le terrain réel crée des **rares réelles** réparties dans le monde. On voyage/commerce
parce qu'il manque *vraiment* :
- **sel** (conserver avant l'hiver, seulement au loin) ;
- **silex / pierre** (outils, là où il n'y en a pas) ;
- **pigments** (peindre = communiquer + mémoriser) ;
- **plante médicinale** (ne pousse qu'ailleurs ; la maladie du doc 08 → voyager pour soigner) ;
- **savoir** perdu ou jamais eu (le voyageur l'enseigne).

La raison est *dans la survie*, pas collée dessus. La nécessité suffit.

## Reformuler « aider la communauté »

Pas « le troc donne un bonus de communauté ». Mais : **« le troc rapporte ce dont les
tiens ont besoin pour vivre → ça fait de toi quelqu'un qui *compte* pour eux. »**
Récompense **relationnelle**, pas mécanique. Le voyageur qui revient avec le sel est
attendu, fêté, nécessaire. = doc 12 (« tu importes parce que tu es perdable », « compter
pour les autres »). La récompense = avoir une **place** et **manquer aux autres**.

## Le but (cohérent, doc 12)

Pas gagner ni s'enrichir. Garder les siens en vie, compter pour eux, laisser une trace,
vivre une vie dont on se souvient. Le « score » = le résumé de vie. Le commerce ne
réclame pas de but propre : il *sert* ce but.

## Honnêteté : c'est un pari, et les bonus le saboteraient

Refuser les récompenses ne paie que si :
1. les **besoins sont réels** (la survie a des dents — l'hiver tue) ;
2. une **communauté se forme** (des gens à qui compter) ;
3. l'**expérience est magique** (Étape 0 réussie).

Ajouter des bonus *maintenant* = cache-misère qui empêche de savoir si ces piliers tiennent.
Résister à la carotte = **garder le diagnostic honnête**. L'Étape 0 teste si l'échange *sans
aucune récompense* procure déjà l'étincelle. Si oui → jamais besoin de bonus. Si non →
aucun bonus ne sauve le jeu, il le déguise.

## Règle

Toute future idée de « bonus / avantage / récompense / buff / déblocage » pour motiver une
action → **drapeau rouge**. Reformuler en **besoin diégétique + conséquence + appartenance
+ trace**. Si on n'y arrive pas, c'est que l'action n'a peut-être pas sa place.
